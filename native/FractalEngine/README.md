# FractalEngine

A Swift 6, macOS 27 library starting the native fractal-engine migration. No Qt,
OpenCL, RealityKit, Metal, package dependencies, or application executable.

## Current coverage

- Pure Swift `SIMD3<Double>` classic Mandelbulb distance estimator.
- Fixed power 8, zero angle offsets, 32 iterations, bailout radius 8.
- Finite coordinates bounded to ±1,000,000; invalid inputs throw `FractalError`.
- CPU single-ray preview marcher, at most 512 steps and 10,000 travel units.
- No global mutable state; result values are `Sendable`.

The formula comes from `mandelbulber2/formula/definition/fractal_mandelbulb.cpp`.
The bounded iteration policy, zero guard, pixel addition and logarithmic DE match
`tests/qrhi/main.cpp`'s CPU-double reference. Golden fixtures were generated by
compiling that existing C++ reference, without translating its implementation.
All 12 original sample points are covered, including five bounded non-escape points.
The test input round-trip through `Float` preserves the oracle's original inputs.

The ray policy follows `tests/qrhi/mandelbulb.comp` (0.7 safety factor, default
128 steps, 0.001 tolerance, distance 7). A hit is an approximate DE threshold;
32-iteration non-escape is not proof of fractal-set membership. Returned travel
for a ray that exceeds the range is clamped to the configured maximum.

## Build and verify

```sh
cd native/FractalEngine
swift build
swift test
```

Verified locally with Apple Swift 6.4, arm64, macOS 27 SDK. SwiftPM's string platform
version expresses macOS 27 without requiring a version-specific manifest constant.

## Not ported

Other formulas and hybrids, configurable Mandelbulb parameters, existing scene
parsing and migrations, camera/image rendering, normals, shading, materials,
lighting, textures, post-processing, animation, mesh export, GPU acceleration,
cancellation, and application UI. This is not the full Mandelbulber engine and is
not production-renderer parity. The package imposes no image allocation policy
because it currently exposes only individual estimates and rays.
