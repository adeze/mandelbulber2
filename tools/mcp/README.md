# Local Mandelbulber MCP

Run from any directory, replacing `/absolute/path/to/mandelbulber2` with this checkout:

```sh
uv run --locked --project /absolute/path/to/mandelbulber2/tools/mcp python /absolute/path/to/mandelbulber2/tools/mcp/server.py
```

Transport: stdio. Requires Python 3.11+, `uv`, and the existing Qt6 application build. Uses the official Python MCP SDK maintenance line (`mcp>=1.28,<2`), pinned by `uv.lock`. The upper bound preserves the selected v1 FastMCP API; upgrading to the newer SDK major is separate work. No cloud service, authentication or GUI IPC.

The executable is resolved relative to the checkout: `build/qt6-release/bin/mandelbulber2.app/Contents/MacOS/mandelbulber2`, falling back to the corresponding `qt6-debug` path. Other packaging layouts require adapting `Renderer.executable()`; no machine-specific paths are embedded.

Tools:

| Tool | Inputs | Result |
| --- | --- | --- |
| `list_examples` | `search=""`, `limit=20` (1–100) | Example paths relative to repository |
| `read_scene` | `path` | Raw UTF-8 `.fract` text, maximum 2 MiB |
| `render_preview` | `scene_path`, `width=256`, `height=256` (1–512 each) | Session `job_id`, state, return code, log tail |
| `render_status` | `job_id` | State, return code, log tail |
| `cancel_render` | `job_id` | Cancel and reap this session's render |
| `get_render_image` | `job_id` | MCP PNG image after successful render |

Preview jobs invoke the existing CLI with `--nogui --never-delete --no-cli-color --format png --res WxH --override opencl_enabled=false`. This is the CPU reference renderer, not the experimental QRhi/Metal prototype. One active render per server; 120-second timeout. Disconnect cancels outstanding jobs. Inputs are snapshotted into unique `build/mcp/<session>/<job>/` directories, containing `scene.fract`, `preview.png`, `process.log` (first 64 KiB). Native application logging is disabled through `--logfilepath` pointing to the platform null device. Output paths are generated by the server. Artifacts remain after disconnect for inspection; remove those directories manually when no longer needed.

Only trusted local scenes belong here. Reads reject resolved paths outside the repository, symlink escapes, wrong extensions and oversized inputs. This filesystem restriction is not a sandbox: the native renderer can evaluate scene scripts and access scene-referenced assets, and may perform normal application initialization in the user's environment. Resolution/time caps do not guarantee a memory bound. Do not use this server for untrusted scene uploads. No arbitrary CLI arguments, output paths or overrides are exposed.

Checks from this directory:

```sh
uv run --locked python -m unittest -v test_server.py
MANDELBULBER_MCP_INTEGRATION=1 uv run --locked python -m unittest -v test_server.py
```

The integration check uses the official stdio client and the actual built application for a 16×16 example render. Unit checks cover path and size limits, bounded commands/output, job ownership, concurrency, cancellation, timeout, shutdown and failed/missing/invalid images.
